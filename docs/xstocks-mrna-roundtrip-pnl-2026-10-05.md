## 这张表说明的三件事

1. **对冲腿是这一笔的亏损来源**，不是现货腿。operator 决定本轮不做永续对冲，
   方向是对的：同样的行情，纯现货是 **+7.37**。
2. **固定成本压得很低**：卖出是挂单返佣（+0.02），X Layer 的 redeem 与桥费都是 0，
   资金费 11 天只有 0.035。真正的大头是 **每次 1 USDG 的提币费**（占 $94 本金的 1.06%）
   和 **卡桥的 3.81**。
3. **规模是下一个约束**：$10/笔时，1 USDG 提币费就是 10% 的成本；
   这一笔因为本金 $94 才压到 1%。要提币费摊薄，要么单笔做大，要么攒几笔一起提。

## 全流程耗时（实测 + 待测）

问题：账户 API 全部正常时，从买入到卖出要多久？能不能在几分钟内完成？

| 环节 | 耗时 | 状态 |
|---|---|---|
| 链上买入（Solana：报价 → 签名 → 广播 → 确认） | 约 10–30 秒 | 待实测 |
| 转到 Kraken 充值地址（SPL transfer） | 约 5–20 秒 | 链上确认待实测 |
| **Kraken 入账确认** | **未知** | **唯一没量过的环节，决定"几分钟"能不能成立** |
| Kraken 卖出（挂单 → 成交） | **1.00 秒** | **实测 2026-10-05** |
| USD → USDG 兑换 | 约 2 秒 | 实测 |
| USDG 提币 → X Layer 链上到账 | **15 秒** | **实测 2026-10-05** |
| （如果从 X Layer 出发）redeem + CCIP 桥到 Solana | **约 25 分钟** | 实测 2026-09-26：源链 21:29:51 → Solana 21:55 |

**结论**：

- **Solana 直买这条路**，除了 Kraken 入账，其余环节都是秒级或几十秒级，
  **大概率能在几分钟内走完**。唯一不确定的是 Kraken 给 SPL 入账要多少个确认。
- **X Layer 出发这条路不可能"几分钟"**：光桥就 25 分钟，加上入账确认只会更长。
  要走这条路，就必须接受几十分钟的持仓暴露。
- 所以下一步值得做的第一个实测是：**往 Kraken 充一笔最小额的 xStock，掐表量入账时间**。
  在那之前，"几分钟完成、风险很小"只能算假设，不能写进策略。
